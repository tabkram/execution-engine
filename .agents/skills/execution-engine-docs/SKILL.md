# Documentation

Follow [documentation](../../../CONTRIBUTING.md#documentation) and the relevant
[validation commands](../../../CONTRIBUTING.md#validation).

- Read the implementation, exported types and tests before describing behavior.
- Update the existing page under `docs/execution/`, `docs/engine/`, `docs/guide/` or `docs/reference/`.
- Keep deployment instructions in [DEPLOYMENT.md](../../../DEPLOYMENT.md); the publishing page includes it.
- Keep the README an overview; use `examples/` for runnable demonstrations and source JSDoc for API details.
- Check defaults, units, return values, error behavior and function/decorator differences. Do not invent output or guarantees.
- Verify affected links and examples, and build the documentation site when pages or navigation change.
